# Índice de memoria

> **Seed de memoria del proyecto.** Copiá este archivo al arrancar una app nueva
> a `~/.claude/projects/<slug>/memory/MEMORY.md` (la memoria persistente del
> harness para ese proyecto). Acá arranca vacío: se va llenando a medida que se
> construyen features.
>
> **Cómo funciona este índice:** es un mapa de las notas de memoria del proyecto.
> Cada línea apunta a un archivo de detalle. Convenciones:
> - **Más reciente primero** dentro de cada sección.
> - **Wikilinks `[[nombre-archivo]]`** para enlazar entre notas relacionadas.
> - **Tags de estado** al lado de cada entrada: hash de commit (`abc1234`),
>   `EN dev`, `SIN COMMITEAR`, `EN CURSO`, etc., para saber de un vistazo dónde
>   vive cada cambio.
